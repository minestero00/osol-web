## 이번 제품 사이트에서 반영한 사실

- 공개 manifest는 Android APK231 / 내부 TestFlight231, 공개 스토어 두 채널은 null이다. 설치 페이지는 Android APK와 **이미 초대된 iPhone 사용자**의 TestFlight 경로를 구분한다. 새 iPhone 참여는 문의이며 참여 확정을 약속하지 않는다.
- 크루 앱 화면은 2026-11-15 개발 베타의 예시 데이터다. 231의 화면이라고 표시하지 않는다. 원본·출처·SHA는 `screenshot-provenance.json`에 있다.
- 지도는 앱의 실제 스타일·지도 데이터와 운영 경로 서버의 미포→송정 탐색 결과를 사용한다. 임의 그림과 시험용 지도 캡처는 제거했다. 합법·안전·오프라인 성공을 보장하지 않는다. Android 지도 저장 제한, 기록과 공유의 차이, 초대 후 앱에서 참여 확인, 같은 기기에서 인증을 완료해야 하는 조건을 도움말에 설명한다.
- 이메일·Google·Apple 로그인만 안내한다. 미구현 Pro 가격/일정이나 사용자 수·후기 등은 만들지 않는다.
- 초대 코드 복사와 로컬 테마 설정을 추가했다. 분석 SDK·외부 폰트·추적 픽셀·위치 요청·지원 폼 전송은 없다. 인증 query/hash는 동일 출처 문서에서 고정 `osol://login-callback`으로 사용자 클릭 시 전달하며 `no-referrer`를 유지한다.
