# 제품 사이트 QA · 2026-11-16

브랜치 `feat/product-site-refresh`, 최신 main `313c25c` 기반. 기본 osol-web 체크아웃만 사용했다. 앱 배포231과 운영 API/DB는 변경하지 않았다. 테스트는 합성 인증·초대 값만 사용하고 실제 앱 실행 기본 동작을 가로채 복구 UI를 확인했다.

## 구현과 발견 수정

- 경로·기록·크루의 쓰임새를 소개하는 홈. 앱의 실제 지도 스타일·운영 타일과 미포→송정87좌표/5,416.5m 탐색 결과를 그대로 렌더했다. 시험용 지도 캡처2개와 임의 경로 도식은 삭제하고 크루의 개발 베타 화면1개만 남겼다.
- 시스템/라이트/다크와 저장 실패 fallback, 기능 영역의 유리 소재, rem서체, 키보드·모션 줄이기. 실제 탐색이 아닌 취향/드래그 체험은 제거했다.
- Android APK / 초대된 iPhone TestFlight 설치 안내, 검색 가능한 도움말, 초대 코드 복사/실패 안내,404와 공유 내비게이션.
- 사용자 피드백에 따라 ‘휴대폰에서 이어서 보기’와 설치 주소 복사 영역은 삭제했다. 반응형 설치 안내만 유지한다.
- 모바일 경로 출발점 가림, 크루 그림 줄바꿈, 좁은 화면 주소 영역 넘침을 초기 검토에서 발견했다. 마지막 주소 영역은 최종적으로 기능 자체를 제거했다.
- 독립 리뷰 발견3개를 수정했다: 검색창 중복× 제거, 이후 제거한 지도 드래그의 글자 선택 방지, 모바일 정책 표의 가로스크롤 안내. 기존 동의 HTML은 수정하지 않고 공유 스타일로 안내를 표시한다.

## 공개 전에 남은 범위

현재 개인정보/약관과 PR5의 실제 구현 불일치는 [사실 대조](release-audit-2026-11-16.md)에 구체적으로 남겼다. 제공자 실제 계약·처리 국가·보관 절차와 정책 공고/시행일은 별도 운영자 검토 대상이다. 새 동의 버전·스토어 출시·앱 빌드 배포·실기기 외부 연동·실주행·사용자 과업 연구를 이 QA로 통과했다고 주장하지 않는다.

`main` 병합은 공개 배포이므로 이번 결과는 draft PR로 제출한다. 소스·검증 증거를 보관하고 소유한 localhost서버를 종료했다. 1차 임시 의존성·npmcache·브라우저 다운로드439,091,200bytes(약419MiB)를 회수했다. 이후 실제 지도 수정에 필요한 의존성을 다시 만들었으며 최종 정리 영수증은 `real-map/cleanup.json`이다. 파일 할당량 기준이며 APFS 여유공간 증가량과 같다는 뜻은 아니다. `cleanup.json`에 소유 경로와 재설치 방법을 기록했다. workspace-audit의 보조 체크아웃0을 확인했다.
