## 3. 수집 방법과 기능 선택

가입·프로필·콘텐츠 입력, 기능 이용 중 기기 권한에 따른 위치·사진·마이크 사용,
서비스 요청, 로그인 제공자와의 인증 연동, 지원 이메일을 통해 정보를 처리합니다.

위치·사진·마이크·알림 권한은 기기 설정에서 변경할 수 있습니다. 권한을 거부하면
관련 기능을 사용할 수 없거나 범위가 제한됩니다. 크루 위치 공유와 음성은 해당
세션 기능을 이용할 때 작동하며, 앱 삭제만으로 서버 계정이나 게시물이 삭제되지는 않습니다.

## 4. 공개·공유 범위

프로필과 공개로 공유한 코스·콘텐츠는 다른 이용자가 볼 수 있습니다. 프로필 사진은
공개 프로필에 사용됩니다. 라이딩 사진은 연결된 주행 기록의 공개 범위에 따른 접근
제한을 사용합니다. 사진의 위치·촬영 시각과 원본 파일에 포함된 메타데이터가 함께
저장될 수 있으므로 공유 전에 사진 내용을 확인해 주세요.

크루 채팅·공유 경로와 세션 위치·음성은 크루 기능의 참가자에게 전달됩니다.
다른 이용자가 Osol 밖에 저장하거나 공유한 사본은 Osol 서버의 원본과 구분됩니다.
서버 내 본인 콘텐츠는 계정 삭제 처리 범위에 포함하며, 외부 사본이 있다는 이유만으로
서버 원본의 보유 기간을 자동으로 늘리지 않습니다.

## 5. 보유·이용 기간과 파기

계정과 연결된 프로필·주행·콘텐츠·설정은 서비스 이용 중 보관하며, 이용자가 삭제한
콘텐츠와 계정 삭제 요청에 따라 삭제를 완료한 데이터는 서비스의 원본 저장소에서
정리합니다. 관계 법령상 별도로 보관해야 하는 자료가 실제 발생하면 해당 항목,
근거와 기간을 따로 안내합니다. 현재 베타에서는 유료 결제 기능을 켜지 않았으므로
유료 거래 자료를 보관하고 있다고 기재하지 않습니다.

> **게시 전 확정할 보유표**: 이 문단만으로 모든 보유 기간을 확정한 것으로 보지 않는다.
> 각 항목은 `retention-and-providers.md`의 실제 처리·정리 조건을 반영해야 한다.
>
> - 삭제 진행 기록: 중단된 요청을 재개할 때 필요한 계정 식별자·작업 해시·상태·시각을
>   처리 완료까지 보관한다. 완료 시 계정 식별자를 지운다.
> - 완료 기록: 계정 식별자를 제거한 작업 해시·상태·생성/완료 시각으로 완료 여부를
>   확인한다. 조회는 30일간 가능하다. **현재 물리 삭제는 다음 삭제 요청 시 수행하는
>   방식이므로 정확히 30일 뒤 지워진다고 표현하지 않는다.** 정기 정리 계약을 확정해야 한다.
> - 운영 작업용 백업: 인증·소셜 DB와 파일 목록의 별도 로컬 백업이 있다. 일반 계정
>   삭제는 이 백업을 자동으로 다시 쓰지 않는다. 보유 만료·백업 파기·복구 시 삭제 요청
>   재적용 절차를 확정해야 한다. 서비스 제공자가 보관하는 내부 백업과는 별개다.
> - 접속·보안·오류 로그와 지원 이메일: 실제 보유 기간 또는 기간 결정 기준과 정리
>   절차를 운영 설정에 맞게 확정해야 한다.

전자적 데이터는 해당 저장소의 삭제 기능을 이용해 정리하고, 별도 보관 근거가 있는
자료는 일반 서비스 데이터와 구분하여 접근 범위와 보유 목적을 제한합니다.

## 6. 외부 서비스 처리와 국외 이전

Osol은 기능 제공을 위해 외부 인증·호스팅·저장·음성·푸시·검색 서비스를 사용합니다.
계정 식별정보와 콘텐츠가 제공자 인프라에서 처리되는 경우와, Osol 서버가 지도 파일이나
교통정보를 가져오는 경우를 구분합니다. 직접 서버를 운영한다는 이유로 외부 사업자가
정보를 전혀 처리하지 않는다고 안내하지 않습니다.

제공자별 실제 데이터 흐름, 확인된 위치와 아직 확인이 필요한 계약 항목은
`retention-and-providers.md`에 정리했습니다. **이 기술 검토표를 최종 위탁·국외 이전
고지의 대체물로 게시하지 않습니다.** 실제 계약의 수탁자 명칭, 업무와 국외 이전의
수령인·항목·국가·시기/방법·목적/기간·거부 방법/효과 및 적용 근거를 확정한 뒤 이 절에
구체적인 표로 넣습니다. DB가 서울이라는 사실만으로 모든 처리가 국내에서 끝난다고
기재하지 않습니다.

## 7. 계정 삭제와 이용자의 권리

이용자는 개인정보 열람·정정·삭제·처리정지를 요청할 수 있습니다. 계정 삭제는
[삭제 요청 페이지](https://osol.minestero.com/delete-account.html) 또는
**superriaco@gmail.com**을 통해 요청할 수 있고 앱 재설치를 요구하지 않습니다.
운영자는 계정 소유 확인 절차와 처리 일정을 안내하고, 처리가 완료되면 그 결과를 알립니다.
본인 확인을 위해 필요한 최소한의 정보만 요청하며 지원 메일로 비밀번호·인증번호·로그인
토큰을 보내지 않도록 안내합니다.

> 앱·서버 배포와 검증 뒤 추가할 문구:
> 새 앱에서는 `설정 → 계정 삭제`에서도 요청할 수 있습니다. 본인 확인 후 계정,
> 프로필, 본인 주행 기록·게시물·사진·프리셋과 연결된 계정 데이터를 정리합니다.
> 크루 리더는 남은 멤버 중 가입이 빠른 멤버에게 이전하고, 남은 멤버가 없으면 크루를
> 삭제합니다. 본인이 시작한 세션과 발행한 공유 경로도 정리합니다. 중간에 끊긴 삭제는
> 재개할 수 있으며, 서버에서 계정 삭제가 끝났음을 확인하기 전에는 완료로 안내하지 않습니다.
> Apple로 연결된 계정은 Apple 재인증과 연결 해제 절차가 필요합니다.

처리 일정은 운영자가 확인한 뒤 안내합니다. 메일 작성 버튼을 누르거나 로그아웃하는
것만으로 요청 처리나 계정 삭제가 완료되는 것은 아닙니다.

## 8. 개인정보의 안전한 처리

운영 API에는 HTTPS를 사용하고 인증·권한 검사와 데이터별 접근 정책을 적용합니다.
공개 프로필·콘텐츠가 있으므로 이용자가 본인 데이터에만 접근한다고 단정하지 않습니다.
정부 API 키와 서버 관리 비밀값은 앱에 포함하지 않고 서버의 비밀 저장 기능으로 관리합니다.
소셜 비밀번호·Apple 인증코드·일시 토큰 등은 각각의 인증 절차에서 필요한 범위로 처리하며
고객지원 이메일로 수집하지 않습니다.
